## §5. F-0048 — пять вопросов по каждому механизму M5

1. **Представление-инварианты (`Dcel`, один конструктор).** Q1: литерала нет, критерий — система типов. Q3: судья — компилятор, проверено атаками (E0451/E0624/E0027).
